# Locked In Wallpapers

Dark mode aesthetic wallpapers for deep focus. 5 themes, 5 sizes each — 25 premium wallpapers designed for productivity.

## What's Included

25 wallpapers across 5 themes, each available in 5 sizes:

| Size | Resolution | Device |
|------|-----------|--------|
| Desktop HD | 1920x1080 | Standard monitors |
| Desktop 2K | 2560x1440 | QHD monitors |
| Desktop 4K | 3840x2160 | 4K monitors / ultrawide |
| Phone | 1290x2796 | iPhone 15 Pro / modern phones |
| Tablet | 2048x2732 | iPad / tablets |

## Themes

### Locked In
Near-black background with a subtle geometric grid pattern. Thin lines form a structured grid with glowing cyan nodes at random intersections. Minimal, structured, focused.

### Deep Focus
Solid dark background with a single centred focal circle — a subtle glow ring effect in muted blue-gray tones. Concentric rings radiate outward. Extremely minimal.

### Night Grind
Dark blue-purple gradient with scattered constellation-like dots in white at varying opacities. A few brighter feature stars with subtle glow effects. Quiet night sky energy.

### Clean Slate
Almost pure black with a subtle noise/grain texture overlay. No patterns, no shapes — just darkness with texture. The most minimal of all five themes.

### Flow State
Dark background with smooth flowing wave lines in muted tones — dark cyan, dark gray, dark blue. Smooth sine-wave curves with organic variations. Subtle and calming.

## How to Use

1. Download the wallpaper pack
2. Find your theme folder
3. Pick the size that matches your device
4. Set as your wallpaper

## Generating (Development)

```bash
npm install
npm run generate
```

Wallpapers are output to the `output/` directory.
