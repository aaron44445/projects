# Project Tracker — Design Specification

## Overview

A multi-project management system built for people running side projects, freelance gigs, or creative endeavors. Combines a kanban board for status tracking, a timeline for deadlines, and revenue tracking so users can see which projects are actually making money. Designed for managing 5-20 projects at various stages.

**For:** Freelancers, creators, and side-hustlers who need one place to see all their projects, know what to work on next, and track which projects generate income.

---

## Database Schema

### Main Database: "Projects"

| Property Name | Type | Details |
|--------------|------|---------|
| Project | Title | The project name. This is the default title property. |
| Status | Select | Options: `Idea` (gray), `Planning` (yellow), `In Progress` (blue), `Shipped` (green), `Paused` (orange), `Archived` (default/light gray) |
| Priority | Select | Options: `High` (red), `Medium` (orange), `Low` (gray) |
| Start Date | Date | When work began (or is planned to begin). Format: date only. |
| Target Date | Date | Deadline or target ship date. Format: date only. |
| Revenue | Number | Total revenue generated by this project. Format: Number with dollar sign ($), no decimal. Set to $0 for projects that haven't made money yet. |
| Revenue Type | Select | Options: `One-Time` (blue), `Recurring` (green), `Not Monetized` (gray) |
| Monthly Revenue | Number | For recurring revenue projects, the monthly amount. Format: Number with dollar sign ($), no decimal. |
| Category | Multi-select | Options: `SaaS` (blue), `Digital Product` (green), `Freelance` (purple), `Content` (orange), `Open Source` (gray), `Personal` (pink), `Client Work` (yellow) |
| Description | Text | What is this project? 1-3 sentence summary. |
| Next Action | Text | The very next thing to do to move this project forward. |
| URL | URL | Link to the live project, repo, or relevant page. |
| Effort | Select | Options: `Small (< 1 week)` (green), `Medium (1-4 weeks)` (yellow), `Large (1-3 months)` (orange), `XL (3+ months)` (red) |
| Impact | Select | Options: `High Impact` (green), `Medium Impact` (yellow), `Low Impact` (gray) |
| Days Until Deadline | Formula | See formula below. |
| ROI Indicator | Formula | See formula below. |
| Notes | Text | Longer-form notes, links, ideas, etc. |
| Tasks | Relation | Links to a "Project Tasks" database (optional, see below). |

### Formula: Days Until Deadline

Calculates how many days remain until the Target Date:

```
if(empty(prop("Target Date")), "No deadline", format(dateBetween(prop("Target Date"), now(), "days")) + " days")
```

**Returns:** A string like "14 days" or "No deadline" if no target date is set.

> **Note:** If the deadline has passed, this returns a negative number like "-3 days". That's intentional — it shows overdue projects. To make it clearer:

```
if(empty(prop("Target Date")), "No deadline", if(dateBetween(prop("Target Date"), now(), "days") < 0, "Overdue by " + format(abs(dateBetween(prop("Target Date"), now(), "days"))) + " days", format(dateBetween(prop("Target Date"), now(), "days")) + " days left"))
```

**Returns:** "14 days left", "Overdue by 3 days", or "No deadline".

### Formula: ROI Indicator

A simple text indicator based on revenue:

```
if(prop("Revenue") > 1000, "Strong", if(prop("Revenue") > 0, "Earning", if(prop("Status") == "Shipped", "No Revenue", "Pre-Launch")))
```

**Returns:** "Strong" (> $1,000), "Earning" (> $0), "No Revenue" (shipped but $0), or "Pre-Launch" (not shipped yet).

### Optional Sub-Database: "Project Tasks"

For users who want task-level tracking within each project. This is a separate database linked via the "Tasks" relation.

| Property Name | Type | Details |
|--------------|------|---------|
| Task | Title | What needs to be done. |
| Project | Relation | Links to "Projects" database. |
| Status | Select | Options: `Todo` (gray), `In Progress` (blue), `Done` (green) |
| Priority | Select | Options: `High` (red), `Medium` (orange), `Low` (gray) |
| Due Date | Date | When this task should be completed. |
| Assignee | Person | Who's responsible (useful if collaborating). |

> **Build note:** The Project Tasks sub-database is optional. Include it in the template but note that some users will prefer using the "Next Action" text field on the main project for simplicity. Both approaches work.

## Views

### 1. Kanban Board (Default View)

| Setting | Value |
|---------|-------|
| **View name** | Board |
| **View type** | Board |
| **Group by** | Status |
| **Filter** | Status is not `Archived` |
| **Sort** | Priority custom order (High, Medium, Low) |
| **Visible properties** | Project, Priority, Category, Next Action, Days Until Deadline |
| **Card preview** | None |
| **Card size** | Small |

**Column order:** Idea, Planning, In Progress, Shipped, Paused

**Result:** Classic kanban. Drag projects between columns as they progress. Archived projects are hidden.

### 2. Timeline

| Setting | Value |
|---------|-------|
| **View name** | Timeline |
| **View type** | Timeline |
| **Timeline by** | Start Date to Target Date (date range) |
| **Filter** | Status is not `Archived` AND Status is not `Idea` |
| **Sort** | Priority custom order |
| **Visible properties** | Project, Status, Priority, Category |
| **Table on left** | Show, with Project and Status columns |
| **Time scale** | Month |

**Result:** Visual timeline showing when projects overlap and when deadlines cluster. Only shows projects that have dates set.

### 3. Priority Table

| Setting | Value |
|---------|-------|
| **View name** | Priority Table |
| **View type** | Table |
| **Filter** | Status is not `Archived` AND Status is not `Idea` |
| **Sort** | Priority custom order (High first), then Days Until Deadline (Ascending) |
| **Group by** | Priority |
| **Visible properties** | Project, Status, Category, Next Action, Target Date, Days Until Deadline, Revenue |

**Result:** Projects grouped by priority level. High priority on top with nearest deadlines first.

### 4. Shipped Gallery

| Setting | Value |
|---------|-------|
| **View name** | Shipped |
| **View type** | Gallery |
| **Filter** | Status = `Shipped` |
| **Sort** | Revenue — Descending |
| **Card preview** | Page content |
| **Card size** | Medium |
| **Visible properties** | Project, Revenue, Revenue Type, Monthly Revenue, Category, URL |

**Result:** A portfolio view of completed/launched projects, sorted by highest revenue. Good for motivation and portfolio building.

### 5. Revenue Tracker

| Setting | Value |
|---------|-------|
| **View name** | Revenue |
| **View type** | Table |
| **Filter** | Revenue > 0 OR Status = `Shipped` |
| **Sort** | Revenue — Descending |
| **Visible properties** | Project, Status, Revenue, Revenue Type, Monthly Revenue, ROI Indicator, Category, URL |

**Result:** Financial view of all projects. See which ones are making money and how much.

### 6. Ideas Backlog

| Setting | Value |
|---------|-------|
| **View name** | Ideas |
| **View type** | List |
| **Filter** | Status = `Idea` |
| **Sort** | Impact custom order (High, Medium, Low), then Effort custom order (Small, Medium, Large, XL) |
| **Visible properties** | Project, Impact, Effort, Category, Description |

**Result:** A clean list of project ideas sorted by potential impact. Good for deciding what to work on next.

### 7. Active Projects

| Setting | Value |
|---------|-------|
| **View name** | Active |
| **View type** | Table |
| **Filter** | Status = `In Progress` |
| **Sort** | Priority custom order, then Target Date — Ascending |
| **Visible properties** | Project, Priority, Next Action, Target Date, Days Until Deadline, Category |

**Result:** Focused view of only what's currently in progress. Shows next actions and deadlines.

## Page Layout

### Row 1: Header
- **Icon:** Rocket emoji
- **Cover:** Notion built-in gradient cover (dark blue/indigo gradient)
- **Title:** "Project Tracker"

### Row 2: Dashboard Summary Callout
- **Block type:** Callout (chart/bar chart emoji)
- **Content:**
  ```
  Quick actions: Use the board to drag projects between stages. Check the "Revenue" view to see what's earning. Review "Ideas" when you're ready to start something new.
  ```

### Row 3: Button Row
- **Layout:** 3 columns
- Column 1: `+ New Project` button
- Column 2: `+ Quick Idea` button
- Column 3: `Start Project` button

### Row 4: Divider
- Horizontal divider line

### Row 5: Active Projects Summary
- **Block type:** H2 heading
- **Text:** "Projects"

### Row 6: Main Database
- **Block type:** Inline database "Projects"
- **Default view:** Board (Kanban)
- **All views as tabs:** Board, Timeline, Priority Table, Shipped, Revenue, Ideas, Active

### Row 7: Divider
- Horizontal divider line

### Row 8: Sub-Tasks Section (Optional)
- **Block type:** H2 heading
- **Text:** "Task Breakdown"
- **Block type:** Linked view of "Project Tasks" database
- **Default view:** Table grouped by Project
