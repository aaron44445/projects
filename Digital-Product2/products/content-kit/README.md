# The Build-in-Public Content Kit

A complete content system for creators and indie builders who want to grow on social media but don't know what to post. Fill in the blanks, post, and grow.

## What's Inside

- **15 TikTok Script Templates** — full Hook-Body-CTA scripts with fill-in-the-blank structure
- **10 Twitter/X Thread Templates** — complete thread frameworks with 6-8 tweets each
- **8 Carousel Templates** — slide-by-slide formats for Instagram and LinkedIn
- **30-Day Content Calendar** — every day mapped with platform, content type, template reference, and best post time
- **20 Hook Formulas** — proven formulas with examples, psychology breakdown, and platform recommendations

## Build the PDF

```bash
npm install
npm run build
```

Output: `output/build-in-public-content-kit.pdf`

## File Structure

```
content-kit/

    twitter-threads.md     # 10 Twitter/X thread templates

    hook-formulas.md       # 20 hook formulas
  build-pdf.js             # PDF generator (pdfkit)
  package.json
  .gitignore
  output/                  # Generated PDF (gitignored)
```
